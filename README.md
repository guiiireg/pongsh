# PongSH

A lightweight, modular Unix shell written in C conforming to Epitech coding standards.

## Compilation

```bash
make
```

## Exécution

```bash
./pongsh
```

## Règles du Makefile

- `make` : compile l'exécutable `pongsh`
- `make clean` : supprime les fichiers objets temporaires
- `make fclean` : supprime les fichiers objets et l'exécutable
- `make re` : recompile l'ensemble du projet
